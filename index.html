Groq-KI-Anbindung

Dein Groq-API-Key wird nur lokal/persönlich gespeichert — nicht im Code der App, nicht mit der Familie geteilt. Er ist trotzdem im Netzwerk-Tab deines Browsers sichtbar, sobald ein Aufruf läuft — das lässt sich bei einem reinen Client-Tool ohne eigenen Server nicht vollständig vermeiden.

Hinweis: Groq kann keine Web-Links selbst lesen — beim Rezept-Import daher immer den Text/die Caption mit einfügen.

YouTube-Anbindung (optional)

Ohne Key erkennt der Rezept-Import YouTube-Links automatisch und holt sich den Video-Titel — die Beschreibung musst du dann noch manuell einfügen. Mit einem kostenlosen YouTube-Data-API-Key wird die komplette Videobeschreibung automatisch geladen, du musst nichts mehr kopieren.

So bekommst du einen Key: console.cloud.google.com → Projekt anlegen → "YouTube Data API v3" aktivieren → Anmeldedaten → API-Schlüssel erstellen.

Instagram bietet uns leider keinen vergleichbaren freien Zugang — dort musst du die Bildunterschrift weiterhin manuell aus der App kopieren und hier einfügen.

Speicherung

Plan-, Pool-, Häkchen- und Einkaufslistendaten laufen jetzt über euer eigenes Firebase-Projekt (Firestore) — familienweit sichtbar und geräteübergreifend synchron. Der Groq-Key bleibt bewusst lokal auf diesem Gerät gespeichert (localStorage), nicht in Firestore, nicht mit der Familie geteilt. Falls Firestore mal nicht erreichbar ist, fällt die App automatisch auf lokalen Speicher zurück, damit nichts verloren geht.
